# Engstien 25

Dansk dashboard til hjemmet med rumstyring, 3D-hus, familielister og enhedsopsætning.

Åbnes gennem Home Assistant. Matter-enheder parres først i Home Assistant Companion og tilføjes derefter enkeltvis i Engstien. Installationen kræver ingen manuelt indtastet HA-adgangsnøgle.

Green samler automatisk sin aarch64-installation ud fra den færdigbyggede GitHub-version. amd64 er også understøttet. Se Dokumentation for installation, opdatering og backup.
